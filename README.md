# Hack.Genesis 2026 — Задача 2. Умный роутинг выплат

Механизм распределения выплат между платёжными провайдерами: на вход — состояние
провайдеров, очередь заявок и история операций; на выход — решение по каждой заявке
с объяснением (кого рассматривали, кого выбрали, кого и почему отсеяли) и отчёт
с аналитикой и рекомендациями.

Полное ТЗ: [docs/case/task.md](docs/case/task.md). Вводные данные организаторов: `data/`,
их скрипт автопроверки: `scripts/validate_10.rb`.

Стек: Ruby 4.0, без нейросетей и проприетарных компонентов (ограничение кейса).

_Раздел «Запуск» появится вместе с кодом решения._
