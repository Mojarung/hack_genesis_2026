# hack_genesis_2026
Хакатон по разработке генератора интеграций с платёжными провайдерами: на вход подаётся OpenAPI-спецификация (например, provider_api.yaml), а решение должно автоматически создавать заготовку программной интеграции, документацию и тестовые примеры, адаптируясь к API разных провайдеров. На каждый трек отбирается 55 команд.
